# Basemap data

`ne_110m_admin_0_countries.geojson` is derived from Natural Earth small-scale
(1:110m) admin-0 country polygons and is used only as a lightweight visual
context layer for the WIGOS Portal PoC.

Natural Earth vector and raster data are in the public domain:
https://www.naturalearthdata.com/about/terms-of-use/

Suggested attribution: **Made with Natural Earth**.
